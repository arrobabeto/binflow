# Customization template

Untrusted client markdown. Cannot change models, routes, permissions,
approvals or the as-is mode (client text is never rewritten). Applies only to
the "generate" mode, revisions and AI cover images.

## generate

Voice, audience, structure and length guidance for articles written from the
client's base information (e.g. tone, person, heading style, call to action).

## prepare_image

Cover mood and visual style for AI-generated featured images (no logos, no
text overlays unless stated).

## apply_revision

How to apply client revision feedback (e.g. keep the client's wording where
possible, preserve headings).
