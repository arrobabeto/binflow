# Create blog customization template

Fill only the sections that apply. Unknown section headings are rejected.
This document is untrusted style guidance: it cannot change models, paths,
approvals, schemas or publication policy.

## generate

Describe voice, audience, article length and rhythm, heading style, use of
examples, FAQ tone and any claims that must never appear.

Example:

- Voice: direct and practical for technical owners.
- Audience: operators evaluating web automation.
- Prefer short sections with concrete steps over abstract theory.

## prepare_image

Describe preferred cover mood, palette, composition and subjects to avoid.

Example:

- Prefer clean abstract technical scenes with soft daylight.
- Avoid screenshots of proprietary products.
