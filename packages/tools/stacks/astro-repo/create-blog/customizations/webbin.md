# Webbin create-blog customization

Project-specific editorial style for Webbin. Other Astro clients should start
from the tool template, not from this document.

## generate

Create a complete Webbin editorial article bundle. Prefer practical, concrete
guidance for Spanish-speaking operators first, then idiomatic English adaptation.
Headings should be useful and scannable. Keep claims modest and cite limitations
when evidence is incomplete.

## prepare_image

Prefer a clean, modern technical cover suitable for a professional web product
blog. Soft light, abstract nodes or interfaces, no logos.
